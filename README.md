# AngelHeart · 天使之心

![天使之心](logo.png)

**被点名才说话的群聊 AI——懂分寸，知进退。**

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)
[![AstrBot Plugin](https://img.shields.io/badge/AstrBot-Plugin-blue)](https://github.com/Soulter/AstrBot)

她在群里是什么样？热闹的时候她安静听着，从不抢话；有人叫到她，她立刻接上，还会轻轻戳一下叫她的人；长文她不会直接刷屏，而是排成一张好看的长图发出来，连字体都能挑。聊久了她也会累，说得多就歇得久一点。

她更像个真正的群友，而不是每条消息都要插一句的复读机。

## 三个角色，各干各的

她不是那种自己判断、又自己开口的 AI。一条消息要过三道手：

- **前台**（不花钱）：把群聊整理成册，安排说话的节奏。
- **秘书**（轻量模型，很便宜）：看一眼气氛，决定这一句要不要接。觉得不必接，事情就到此为止——贵的模型根本不醒来。
- **助理**（你的主模型）：只在秘书放行后开口，负责把话说好听。

所以她既不会见话就接，也不会对着半句话作答。你打字的时候前台会等你说完，只让最后一句触发判断。

## 懂进退

她在群里只有两种状态：

- **离场**：默认安静潜水，只记不说话。只有被 @ 或叫到唤醒词才进场。也可以打开「离场应答」：群里刷复读、多人热聊的时候她冒出来回一句——只回一句，回完继续潜水。
- **在场**：被点名后加入聊天。之后接不接话，交给秘书看气氛；群聊安静一段时间，她自己就退场了，下次再叫她就好。

## 她也会累

说话是耗力气的，长篇大论尤其累。每次开口都会消耗能量，说得越多消耗越大；能量随时间慢慢恢复，耗光了她就先歇着，过一会儿又精神了。

- **点名永远有效**：再累也会应你的召唤（但会等上一轮说完，不抢麦）。
- **短回复恢复快**：两三句的短话耗能少，她更愿意常开口；长回复要多歇一会儿再说话。
- 具体数值都在「能量设置」里可调，默认值开箱即用。

## 长文不刷屏

回复超过字数阈值自动排成竖版长图再发，群里不再被长文刷屏。字体面板提供三款霞鹜字体随心切换——新晰黑、新致宋、文楷，没下载的点一下就自动下好；想用自己的字体，直接上传就行。

## 每个群可以不一样

人设、唤醒词、回复长度、能量、说话节奏，都能按群绑定配置模板；没绑定的群用全局默认。

插件页面里还有**联系人监控**：哪个群在场、剩多少能量、最近一次为什么回（或不回），三秒一刷尽收眼底。她最近十次「看到了什么、问了什么」的请求原文也随时可查——她说错话的时候，你可以直接翻她的记忆。

### 群聊发送者忽略与昵称唤醒冷却

在「点名与交互」中可配置以下两项，也可通过群聊绑定的模板分别覆盖；默认值保留原有行为。

| 配置项 | 默认值 | 行为 |
|--------|--------|------|
| `wake_interaction.ignored_sender_ids` | `[]` | 要忽略的群聊发送者 ID，使用字符串列表，例如 `["123456", "654321"]` |
| `wake_interaction.alias_wake_cooldown_seconds` | `1` | 昵称唤醒冷却秒数，支持小数；`0` 表示不限制 |

忽略规则在上游命令旁路之后执行：命中列表的群聊发送者，其后续消息会被停止，不写入新历史、不进入秘书或双防抖，也不会替换、加速或取消已有待处理请求。配置前已经写入的历史仍保留。

昵称冷却按完整会话来源（`unified_msg_origin`，含平台实例与群聊标识）独立计时，同一会话所有发送者共享。首次昵称点名放行后开始冷却；冷却期间再次叫昵称会按普通消息规则入账和调度，不会延长冷却。直接 @ 机器人、引用回复机器人和命令不受昵称冷却影响；两项配置都不影响私聊。

### 能量：助理也会累

- 刚上线时精力充沛，聊什么都有劲。
- 说一次话会消耗一部分精力；发言越长，消耗越多。
- 累了就先歇着，等精力恢复一些，再由秘书判断要不要接话。
- 如果有人直接点名助理，点名会进入对应防抖；到期放行仍受助理忙碌和休息门闩约束，但不受精力门槛限制。

具体规则：

- 每次秘书普通巡检前，会按**经过的时间**自动恢复一点精力，不会超过上限。
- 精力够，秘书才进入判断；精力不够，保留巡检记录并重新计时，等恢复后再判断。
- **点名巡检**和**离场一次性应答**不受精力限制；点名仍会检查助理忙碌和休息门闩。
- 助理发出回复后，按实际内容消耗精力：

```text
消耗 = 基础消耗（默认 14） + 有效字符数 × 每字符消耗（默认 0.12）
```

短回复耗能少、恢复快，可以更频繁接话；长回复耗能多，说完需要更长时间恢复。扣到下限后不再继续扣，不会把助理卡死。

默认数值：

| 参数 | 默认值 | 含义 |
|------|--------|------|
| 初始精力 / 上限 | 100 | 一开始精力充沛，恢复也不超过此值 |
| 精力下限 | -100 | 扣到底后不再继续扣 |
| 每秒恢复 | 0.6 | 大约 3 分钟从空恢复到满 |
| 回复基础消耗 | 14 | 每次开口的基础代价 |
| 每字符消耗 | 0.12 | 说得越多越累 |

精力按群独立保存在内存中，插件重启后回到初始值。`[能量设置]` 分组可调整全部参数；修改后新巡检立即生效，已有群的当前精力不重置。

### 群聊独立配置与联系人监控

不同群可以绑定不同配置模板：人设、唤醒词、回复长度、能量、回复节奏都可以按群定制。未绑定的群继续使用全局配置。模板中未覆盖的字段也继承全局配置。模板分组的「恢复全局配置」会清除该组覆盖，保存后持续跟随全局设置；全局设置页的「恢复默认」使用插件默认值。

插件页面提供「联系人监控」视图，实时查看每个群或私聊的运行状态：

- 当前是在场还是离场
- 剩余能量
- 巡检 / 等待进度
- 最近一次是否决定回复及原因

状态每 3 秒自动刷新。字段说明以插件 WebUI 和 `_conf_schema.json` 为准。

### 上下文与图片

- **群聊上下文接管**：完整对话连同发言人、时间戳一起交给助理，谁说的、什么时候说的，清清楚楚。私聊消息同样入册，由主框架直接回复。
- **按需图片理解**：模型需要看某张图的细节时才调用 `angel_describe_image`，不为每张图都付一次理解的钱。

## 快速开始

前置：AstrBot 已安装并运行，至少一个可用的模型（推荐再配一个便宜的轻量模型当秘书）。

1. **市场安装**：在 AstrBot 的插件市场里搜「天使之心」。
2. **手动安装**：把本仓库克隆或下载到 AstrBot 的 plugins 目录。

装好后在插件配置里指定秘书模型，按需打开群聊上下文接管，就能开工了。所有配置都带中文说明，在 WebUI 里看着调即可。
